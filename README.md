# Central Alberta Snow Radar (v5)

Single-file web page: ECCC MSC GeoMet snow radar + HRDPS snowfall forecast, Open-Meteo town conditions
(modelled), Leaflet map. No API keys, no build step. `index.html` is the whole app.
